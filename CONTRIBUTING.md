# Contributing

This repository is a published copy of the client apps, synced from SpaceFleet's private
monorepo. Commits here are made by that sync, so pull requests are not merged as they are:
when one is useful, we apply the change in the monorepo and it comes back here with the
next sync, credited to you.

- Bugs and ideas: open an issue on https://github.com/spacefleet-io/clients/issues.
- Help with your account or the apps: support@spacefleet.io.
- Security issues: do not open a public issue; write to security@spacefleet.io.

By sending a change you agree to license it under GPL-3.0-only, with the additional
permission in `LICENSE-EXCEPTION.md` where the directory you change has one.
